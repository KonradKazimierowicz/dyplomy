Rozszerzenie może być .png, .svg albo .jpg.

| Patronat | Urząd Miasta Głogowa | `urzad-miasta-glogowa` |

| Partnerzy | KGHM Polska Miedź, Wolontariat | `kghm` |
| Partnerzy | Powiat Głogowski | `powiat-glogowski` |

| Partnerzy | KojotCar | `kojotcar` |
| Partnerzy | Only Cars Studio | `only-cars-studio` |

Na przykład `kghm.png`. Logo dostaje stałą wysokość i zachowuje proporcje.
Dopóki pliku nie ma, na dyplomie widać nazwę partnera.
Lista i kolejność są w `app.js`, w tablicy `SPONSORZY`.
